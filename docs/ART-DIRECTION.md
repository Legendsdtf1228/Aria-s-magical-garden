# Art Direction — Aria’s Magical Garden V4

## Purpose
Original bright 2D preschool-cartoon world for Aria (age 3). The game must feel like an illustrated interactive children’s book—not a website.

## Style
- Rounded full-body characters, clean outlines, soft dimensional shading
- Large expressive eyes, readable silhouettes, consistent proportions
- Warm sunlight, layered scenery (sky / midground / foreground)
- Soft ground shadows; foreground flowers frame the bottom
- Aspect ratio preserved (`object-fit: contain`) — never stretch

## Forbidden
- Emoji as primary artwork
- White rectangular cards / website panels
- Flat green hill bands as the whole environment
- CSS circles as finished characters
- Clip-art mixtures or branded lookalikes
- Text required to play

## Scene list (production)
Welcome Garden · Main Garden Map · Color Flower Patch · Animal Meadow · Feeding Picnic · Sound Forest · Garden Care Beds · Free Play Garden · Shape Meadow · Counting Pond · Music Gazebo · Animal Trail

## Characters (full body)
Butterfly · Bunny · Bird · Ladybug · Bee · Frog · Cat · Puppy  
Poses: idle, blink, tap, move, celebrate, eat/interact, rest

## Child controls
Home · Replay instruction only  
Language / volumes / reset / install / reduced-motion → parent flower gate

## Milestone gate
Vertical slice (Welcome + Map + Counting Pond) must pass visual approval before redesigning remaining activities.
